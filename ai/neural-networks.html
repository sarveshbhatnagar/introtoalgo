Neural Networks

Build a network from simple units, see why layers need a bend to be useful, trace a tiny network by hand, and learn how backpropagation trains it.

A hallway has a light switch at each end. Flip either one and the light changes. So with both switches down the light is off, with exactly one up it is on, and with both up it is off again. Simple to describe, and yet none of the models in this module so far can learn it.

That small failure is the reason neural networks exist. Fixing it takes one new idea, stacking simple units in layers with a bend between them, and that same idea, scaled up enormously, is behind image recognition, speech recognition and language models.

#Why one weighted sum is not enough

The classifier in Regression and Classification computes a weighted sum of the features and compares it with a threshold. Geometrically, that draws one straight line through the space of inputs: on one side "yes", on the other "no".

But suppose you first computed two new features: "how many switches are up" and "are both up". Then the answer is easy: count minus twice "both". With 1 switch up that gives 1. With 2 up it gives 2 − 2 = 0. A network learns intermediate features like these on its own.

#The building block: a neuron

A neuron in a network is three small steps:

  1. Multiply each input by its weight and add them up.
  2. Add a bias.
  3. Pass the result through an activation function.

The first two steps are exactly the weighted sum you already know. The third adds the bend. The most common activation is ReLU: keep the number if it is positive, otherwise output 0. In code, max(0, z).

Neurons are arranged in layers. The inputs feed a hidden layer, the hidden layer's outputs feed the next layer, and the last layer gives the answer. "Deep learning" just means networks with many hidden layers.

#Trace the hallway network

Here is a network with two hidden neurons that solves the hallway problem. The weights are set by hand so you can follow every number; training would find weights that work just as well.

  • h1 = ReLU(s1 + s2): how many switches are up.
  • h2 = ReLU(s1 + s2 − 1): 1 only when both are up, because the bias of −1 cancels a single switch.
  • light = h1 − 2 × h2.

Switch 2 alone works like switch 1 alone and gives 1. All four positions come out right. Running inputs through the network to get an output like this is called the forward pass.

function relu(z) {
  return Math.max(0, z);
}
 
// Weighted sum of the inputs, plus the bias.
function weightedSum(inputs, weights, bias) {
  let z = bias;
  for (let i = 0; i < inputs.length; i++) z += inputs[i] * weights[i];
  return z;
}
 
// Two switches in, light out (1 = on).
function hallwayLight(s1, s2) {
  const h1 = relu(weightedSum([s1, s2], [1, 1], 0));  // switches up
  const h2 = relu(weightedSum([s1, s2], [1, 1], -1)); // both up?
  return weightedSum([h1, h2], [1, -2], 0);
}
 
hallwayLight(0, 0); // 0
hallwayLight(1, 0); // 1
hallwayLight(1, 1); // 0
def relu(z):
    return max(0, z)
 
def weighted_sum(inputs, weights, bias):
    """Weighted sum of the inputs, plus the bias."""
    return bias + sum(x * w for x, w in zip(inputs, weights))
 
def hallway_light(s1, s2):
    """Two switches in, light out (1 = on)."""
    h1 = relu(weighted_sum([s1, s2], [1, 1], 0))   # switches up
    h2 = relu(weighted_sum([s1, s2], [1, 1], -1))  # both up?
    return weighted_sum([h1, h2], [1, -2], 0)
 
hallway_light(0, 0)  # 0
hallway_light(1, 0)  # 1
hallway_light(1, 1)  # 0

#Why the bend matters

Remove ReLU and see what happens with school algebra. The output becomes

(s1 + s2) − 2 × (s1 + s2 − 1) = 2 − s1 − s2

That is one weighted sum again, a straight line, and it gives 2 for both switches down. Stacking layers of plain weighted sums always collapses into a single weighted sum, however many layers you add. The activation function is what lets each layer build something new on top of the last.

Key idea

A neural network is layers of weighted sums with a simple bend after each one. The bends let later layers combine earlier features into new ones, which is what a single weighted sum cannot do.

#How a network is trained

Training uses the loop from How Models Learn: start with small random weights, run the forward pass, measure the loss, compute the gradient for every weight, and step downhill. The only hard part is the gradient, because a weight in the first layer affects the output through every layer after it.

The trick is to multiply rates of change along the path. Take the weight from s1 to h2, with both switches up. Nudge it up by 0.01. Then h2 rises by 0.01 × 1 = 0.01, because s1 is 1. And the output changes by −2 times whatever h2 changes, so it falls by 0.02. The rate for that weight is 1 × (−2) = −2: the rates along the path, multiplied together. This is the chain rule.

Backpropagation does this for every weight at once, starting at the output and working backwards layer by layer, reusing each layer's rates for the layer before it. One backward sweep costs about as much as one forward pass, which is why networks with millions or billions of weights can be trained at all.

In the real world

In image models, early layers tend to learn edges and color patches, middle layers combine them into textures and parts, and late layers respond to whole objects. Nobody programs those features. They appear because they help lower the loss.

#Common mistakes

Forgetting the activation function

A network without activations, however deep, is one weighted sum in disguise, as the algebra above shows. If a network cannot learn a pattern that should be easy, check that every hidden layer has its activation.

Feeding inputs on wildly different scales

If one input is an age (around 40) and another is an income (around 40,000), the income dominates every weighted sum and gradient steps behave badly. Rescale inputs to similar ranges, for example by subtracting the average and dividing by the spread, before training.

Taking the brain comparison literally

The word "neuron" is a loose metaphor. Each unit is a weighted sum and a max. A network that labels photos well has learned patterns that lower its loss, not an understanding of what it sees, and it can fail in ways no person would.

#Try it yourself

Try it: Rewire the output

Keep the two hidden neurons exactly as they are: h1 counts the switches that are up, and h2 is 1 only when both are up. Choose new output weights so that (a) the light is on only when both switches are up, and (b) the light is on when at least one switch is up. Check all four positions for each.

Show a sample answer

(a) Both up: light = 0 × h1 + 1 × h2. Positions (0,0), (1,0), (0,1), (1,1) give 0, 0, 0, 1.

(b) At least one up: light = 1 × h1 − 1 × h2. The four positions give 0, 1, 1, 2 − 1 = 1.

The hidden layer did not change at all, only the last layer's weights. That is what learned features buy you: once a network has computed useful intermediate signals, many different answers are a simple weighted sum away.

#Check yourself

Quick check

A neuron's weighted sum plus bias is −3. What does ReLU output?

  1. Not quite. ReLU only passes positive values through unchanged.
  2. Right. ReLU is max(0, z), so any negative value becomes 0.
  3. Not quite. ReLU does not flip the sign. It replaces negative values with 0.

You build a 10-layer network but forget every activation function. What can it learn?

  1. Not quite. Without activations, the layers collapse into one weighted sum. It loses ability, not just speed.
  2. Right. Weighted sums of weighted sums are still one weighted sum. It cannot solve the hallway problem.
  3. Not quite. It can still learn anything a single weighted sum can, like a straight-line fit.

What does backpropagation compute?

  1. Not quite. That is the forward pass.
  2. Right. It computes the gradient for every weight in one backward sweep, by multiplying rates of change along each path.
  3. Not quite. It only gives the downhill direction. Gradient descent still takes many small steps.

#What to practise next

The hidden values inside a network are lists of numbers that capture what the network has learned about its input. Embeddings takes that idea and turns it into one of the most useful tools in applied AI: representing words, documents and products as points where similar things sit close together.
