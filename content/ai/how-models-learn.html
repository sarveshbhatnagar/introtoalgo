You are on a hillside in thick fog, trying to reach the bottom of the valley. You can only feel the ground under your feet. So you feel which way it slopes down, step that way, and repeat. When the ground feels flat, you are at the bottom.

That is how most modern models learn, neural networks included. The height is how wrong the model is. Your position is the values of its parameters. The step-downhill rule is called gradient descent.

A model with one dial

In What Is Machine Learning we tried every candidate value. That fails when a parameter can be any number, or there are thousands of them. You need to improve the parameters a little at a time.

A courier app estimates trip time from distance with the model:

minutes = w × km

The parameter w is minutes per km. Two past trips: 1 km took 3 minutes, 3 km took 9. The answer is clearly w = 3; watch a method find it without being told.

Step 1: measure how wrong the model is

For each example, the error is the prediction minus the real answer. With w = 0, the model predicts 0 for both trips, so the errors are −3 and −9.

Square each error and take the average. That number is the loss, and this version is the mean squared error:

loss = ((−3)² + (−9)²) / 2 = (9 + 81) / 2 = 45

Squaring makes every error positive, so too-high and too-low guesses cannot cancel, and it punishes big errors more: 9 costs 81, nine times an error of 3. Training means finding the w with the lowest loss.

Step 2: find which way is downhill

Plot the loss for every w and you get a valley, with the bottom at w = 3, loss 0.

The gradient is the slope of that curve at your current w: how much the loss changes when you nudge w up a tiny bit. If it is negative, raising w lowers the loss.

School algebra gives the slope. Take one example with input x, answer y and error e = w·x − y. Nudge w up by a tiny h. The new error is e + h·x, and its square is:

(e + h·x)² = e² + 2·e·x·h + (h·x)²

When h is tiny, the last term is negligible, so the squared error grows by about 2·e·x per unit of h. Average that over all examples:

gradient = average of 2 × error × input

Step 3: take a step, and repeat

Move w a little against the gradient:

w = w − learning rate × gradient

The learning rate sets the step size. Here it is 0.05.

The steps shrink by themselves because the gradient flattens near the bottom.

The code

// Average squared error of the model minutes = w * km.
function loss(w, km, minutes) {
  let total = 0;
  for (let i = 0; i < km.length; i++) {
    const error = w * km[i] - minutes[i];
    total += error * error;
  }
  return total / km.length;
}

// Slope of the loss at w: average of 2 * error * input.
function gradient(w, km, minutes) {
  let total = 0;
  for (let i = 0; i < km.length; i++) {
    const error = w * km[i] - minutes[i];
    total += 2 * error * km[i];
  }
  return total / km.length;
}

let w = 0;
for (let step = 1; step <= 5; step++) {
  w = w - 0.05 * gradient(w, [1, 3], [3, 9]);
}
// w is 2.90625, loss(w, [1, 3], [3, 9]) is about 0.044

def loss(w, km, minutes):
    """Average squared error of the model minutes = w * km."""
    errors = [w * x - y for x, y in zip(km, minutes)]
    return sum(e * e for e in errors) / len(km)

def gradient(w, km, minutes):
    """Slope of the loss at w: average of 2 * error * input."""
    total = 0
    for x, y in zip(km, minutes):
        error = w * x - y
        total += 2 * error * x
    return total / len(km)

w = 0
for step in range(5):
    w = w - 0.05 * gradient(w, [1, 3], [3, 9])
# w is 2.90625, loss(w, [1, 3], [3, 9]) is about 0.044

From one dial to millions

A real model has many parameters. For each one, ask "if I nudge just this, how does the loss change?" That list of slopes is the gradient, and every parameter steps downhill at once.

Two things change at scale:

  • Batches. Each step uses a small random batch, not all millions of examples. Noisier, but far cheaper.
  • Many dips. The loss surface has many low points, so gradient descent finds a good one, not a guaranteed best. That is usually enough.

Learning is a loop: predict, measure the loss, find which way each parameter should move, and take a small step.

Common mistakes

With a rate of 0.25, w jumps from 0 to 7.5, over the valley, then to −3.75, then 13.125. The loss grows from 45 to 101.25 to about 228. If the loss goes up, lower the rate first.

With a rate of 0.005, five steps only get w to about 0.68. The sign: a loss that barely moves.

The gradient points uphill. w + rate × gradient climbs away from the answer. Always step against the slope.

Try it yourself

Same two trips, same learning rate 0.05, but start too high, at w = 4. Work out the errors, the loss, the gradient and the new w. Which way did it move, and why?
  • Predictions: 4 × 1 = 4 and 4 × 3 = 12. Errors: 4 − 3 = 1 and 12 − 9 = 3.
  • Loss: (1² + 3²) / 2 = (1 + 9) / 2 = 5.
  • Gradient: (2 × 1 × 1 + 2 × 3 × 3) / 2 = (2 + 18) / 2 = 10.
  • New w: 4 − 0.05 × 10 = 3.5. The loss there is (0.5² + 1.5²) / 2 = 1.25.

w went down. The errors were positive (guesses too long), so the gradient was positive: the loss rises if w rises. Stepping against it lowers w. One formula handles both sides of the valley.
