A hallway has a light switch at each end. Flip either one and the light changes. Both down: off. Exactly one up: on. Both up: off again. Simple, yet the weighted-sum classifier from Regression and Classification cannot learn it, whatever its weights.

The fix: stack simple units in layers, with a bend between them. That is a neural network, and scaled up it drives modern image, speech and language models.

Why one weighted sum is not enough

That classifier compares a weighted sum of the features with a threshold. Geometrically, it draws one straight line through the inputs: "yes" on one side, "no" on the other.

But compute two new features first, "how many switches are up" and "are both up", and the answer is count minus twice "both": 1 for one switch, 2 − 2 = 0 for two. A network learns intermediate features like these itself.

The building block: a neuron

A neuron is three small steps:

  1. Multiply each input by its weight and add them up.
  2. Add a bias.
  3. Pass the result through an activation function.

The first two are the weighted sum you know; the third adds the bend. The most common activation is ReLU: keep the number if positive, otherwise 0. In code, max(0, z).

Neurons are arranged in layers. The inputs feed a hidden layer, which feeds the next, and the last layer gives the answer. "Deep learning" means many hidden layers.

Trace the hallway network

This network with two hidden neurons solves the hallway problem. The weights are set by hand so you can follow every number; training could find others that also work.

  • h1 = ReLU(s1 + s2): how many switches are up.
  • h2 = ReLU(s1 + s2 − 1): 1 only when both are up, because the bias of −1 cancels a single switch.
  • light = h1 − 2 × h2.

Switch 2 alone also gives 1, so all four positions are right. Running inputs through to get an output is the forward pass.

function relu(z) {
  return Math.max(0, z);
}

// Weighted sum of the inputs, plus the bias.
function weightedSum(inputs, weights, bias) {
  let z = bias;
  for (let i = 0; i < inputs.length; i++) z += inputs[i] * weights[i];
  return z;
}

// Two switches in, light out (1 = on).
function hallwayLight(s1, s2) {
  const h1 = relu(weightedSum([s1, s2], [1, 1], 0));  // switches up
  const h2 = relu(weightedSum([s1, s2], [1, 1], -1)); // both up?
  return weightedSum([h1, h2], [1, -2], 0);
}

hallwayLight(0, 0); // 0
hallwayLight(1, 0); // 1
hallwayLight(1, 1); // 0

def relu(z):
    return max(0, z)

def weighted_sum(inputs, weights, bias):
    """Weighted sum of the inputs, plus the bias."""
    return bias + sum(x * w for x, w in zip(inputs, weights))

def hallway_light(s1, s2):
    """Two switches in, light out (1 = on)."""
    h1 = relu(weighted_sum([s1, s2], [1, 1], 0))   # switches up
    h2 = relu(weighted_sum([s1, s2], [1, 1], -1))  # both up?
    return weighted_sum([h1, h2], [1, -2], 0)

hallway_light(0, 0)  # 0
hallway_light(1, 0)  # 1
hallway_light(1, 1)  # 0

Why the bend matters

Remove ReLU and the output becomes

(s1 + s2) − 2 × (s1 + s2 − 1) = 2 − s1 − s2

That is one weighted sum again, a straight line, and it gives 2 for both switches down. Layers of plain weighted sums always collapse into one. The activation is what lets each layer build something new.

A neural network is layers of weighted sums with a simple bend after each. The bends let later layers combine earlier features into new ones.

How a network is trained

Training uses the loop from How Models Learn, starting from small random weights. The hard part is the gradient, because a first-layer weight affects the output through every later layer.

The trick is to multiply rates of change along the path. Take the weight from s1 to h2, both switches up, and nudge it up by 0.01:

  • h2's sum rises by 0.01 × 1 = 0.01, because s1 is 1.
  • ReLU passes the change through, because its input (1) is positive.
  • The output changes by −2 times that, so it falls by 0.02.

The rate is 1 × 1 × (−2) = −2, multiplied along the path. This is the chain rule. One more factor, how the loss changes with the output, gives the loss gradient.

Backpropagation does this for every weight at once, working backwards from the output and reusing each layer's rates for the layer before. One backward sweep costs a small multiple of one forward pass, which is why networks with billions of weights can be trained at all.

In image models, early layers tend to learn edges and colors, middle layers textures and parts, late layers whole objects. Nobody programs these; they appear because they lower the loss.

Common mistakes

Without activations, any depth of network is one weighted sum. If an easy pattern will not learn, check every hidden layer has its activation.

If one input is an age (around 40) and another an income (around 40,000), income dominates every sum and gradient steps behave badly. Rescale inputs to similar ranges first, for example by subtracting the average and dividing by the spread.

"Neuron" is a loose metaphor: each unit is a weighted sum and a max. A network that labels photos well has learned patterns that lower its loss, not understanding, and it can fail in ways no person would.

Try it yourself

Keep the hidden neurons: h1 counts switches up, h2 is 1 only when both are up. Choose output weights so that the light is on (a) only when both are up, and (b) when at least one is up. Check all four positions.

(a) Both up: light = 0 × h1 + 1 × h2. Positions (0,0), (1,0), (0,1), (1,1) give 0, 0, 0, 1.

(b) At least one up: light = 1 × h1 − 1 × h2. The four positions give 0, 1, 1, 2 − 1 = 1.

Only the last layer changed. That is what learned features buy you: once a network has useful intermediate signals, many answers are a simple weighted sum away.
