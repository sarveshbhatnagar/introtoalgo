The café from Prefix Sums has eight days of takings: 5, 2, 6, 3, 1, 4, 7, 2. The owner keeps asking "how much from day 3 to day 7?", and the bookkeeper keeps correcting old days.

Prefix sums answer a range in O(1), but a correction changes every later total: O(n). A plain array is the opposite. You want both fast.

The idea: precompute sums of blocks

Split the days in half, then each half in half, down to single days, and store every block's total. A range is then a few whole blocks, and a correction touches one block per level.

That is a segment tree: a binary tree where each node stores the sum of a range, each child covers half its parent's range, and the leaves are single values. Store it like a heap: node i has children 2i + 1 and 2i + 2. Here node 0 covers indexes 0 to 7 (30), node 1 covers 0 to 3 (16), node 2 covers 4 to 7 (14), down to the leaves at nodes 7 to 14.

Answering a range query

Days 3 to 7 are indexes 2 to 6. Start at the root and ask each node: how does my range overlap the query?

  • Not at all: contribute 0 and stop.
  • Completely inside: contribute the stored sum and stop.
  • Partly: ask both children and add their answers.

The query is O(log n): at each of the about log₂(n) levels, at most two nodes are partial (the ones holding the query's edges), and everything between them stops at once.

Changing one value

Day 3 (index 2) was really 11, not 6. Change the leaf, then walk up to the root, recomputing each parent from its two children.

class SegmentTree {
  constructor(values) {
    this.n = values.length;
    this.tree = new Array(4 * this.n).fill(0);
    if (this.n > 0) this.build(values, 0, 0, this.n - 1);
  }
  build(values, node, lo, hi) {
    if (lo === hi) { this.tree[node] = values[lo]; return; }
    const mid = Math.floor((lo + hi) / 2);
    this.build(values, 2 * node + 1, lo, mid);
    this.build(values, 2 * node + 2, mid + 1, hi);
    this.tree[node] = this.tree[2 * node + 1] + this.tree[2 * node + 2];
  }
  // Sum of values[left..right], both included.
  query(left, right, node = 0, lo = 0, hi = this.n - 1) {
    if (right < lo || hi < left) return 0;                 // no overlap
    if (left <= lo && hi <= right) return this.tree[node]; // fully inside
    const mid = Math.floor((lo + hi) / 2);
    return this.query(left, right, 2 * node + 1, lo, mid) +
           this.query(left, right, 2 * node + 2, mid + 1, hi);
  }
  // Set values[index] = value.
  update(index, value, node = 0, lo = 0, hi = this.n - 1) {
    if (lo === hi) { this.tree[node] = value; return; }
    const mid = Math.floor((lo + hi) / 2);
    if (index <= mid) this.update(index, value, 2 * node + 1, lo, mid);
    else this.update(index, value, 2 * node + 2, mid + 1, hi);
    this.tree[node] = this.tree[2 * node + 1] + this.tree[2 * node + 2];
  }
}

class SegmentTree:
    def __init__(self, values):
        self.n = len(values)
        self.tree = [0] * (4 * self.n)
        if self.n > 0:
            self._build(values, 0, 0, self.n - 1)

    def _build(self, values, node, lo, hi):
        if lo == hi:
            self.tree[node] = values[lo]
            return
        mid = (lo + hi) // 2
        self._build(values, 2 * node + 1, lo, mid)
        self._build(values, 2 * node + 2, mid + 1, hi)
        self.tree[node] = self.tree[2 * node + 1] + self.tree[2 * node + 2]

    def query(self, left, right, node=0, lo=0, hi=None):
        """Sum of values[left..right], both included."""
        if hi is None:
            hi = self.n - 1
        if right < lo or hi < left:
            return 0                      # no overlap
        if left <= lo and hi <= right:
            return self.tree[node]        # fully inside
        mid = (lo + hi) // 2
        return (self.query(left, right, 2 * node + 1, lo, mid) +
                self.query(left, right, 2 * node + 2, mid + 1, hi))

    def update(self, index, value, node=0, lo=0, hi=None):
        """Set values[index] = value."""
        if hi is None:
            hi = self.n - 1
        if lo == hi:
            self.tree[node] = value
            return
        mid = (lo + hi) // 2
        if index <= mid:
            self.update(index, value, 2 * node + 1, lo, mid)
        else:
            self.update(index, value, 2 * node + 2, mid + 1, hi)
        self.tree[node] = self.tree[2 * node + 1] + self.tree[2 * node + 2]

Nothing here is specific to sums. Combine with min and the same code answers "smallest value from index 2 to 6". Any combine step that works in any grouping fits: sum, min, max, greatest common divisor.

Fenwick trees: the compact version

For sums only, a Fenwick tree (or binary indexed tree) does the job with one array of n + 1 numbers and two tiny loops.

Slots are numbered from 1. Slot i stores the sum of the last lowbit(i) items up to item i, where lowbit(i) is the lowest 1 bit of i, written i & -i (see Bit Manipulation). Slot 6 is 110 in binary, lowest bit 2, so it holds items 5 and 6. Slot 7 holds one item; slot 8 holds all eight.

  • Total of the first i items: add slot i, jump to i − lowbit(i), repeat until 0. For 7: slots 7, 6, 4.
  • Add to item i: add to slot i, jump to i + lowbit(i) (the next block covering item i), repeat while inside the array. For item 3: slots 3, 4, 8.

Each jump removes or carries a 1 bit, so either loop runs at most about log₂(n) times. Here is the same correction, then a query.

The code takes 0-based indexes and shifts by one inside, so the sum of left..right is first(right + 1) − first(left), as with prefix sums.

class Fenwick {
  constructor(n) { this.t = new Array(n + 1).fill(0); }
  add(index, delta) { // values[index] += delta
    for (let i = index + 1; i < this.t.length; i += i & -i) this.t[i] += delta;
  }
  first(count) { // sum of the first count values
    let s = 0;
    for (let i = count; i > 0; i -= i & -i) s += this.t[i];
    return s;
  }
  rangeSum(left, right) { return this.first(right + 1) - this.first(left); }
}

const fw = new Fenwick(8);
[5, 2, 6, 3, 1, 4, 7, 2].forEach((v, i) => fw.add(i, v));
fw.add(2, 5);
fw.first(7);       // 33
fw.rangeSum(2, 6); // 26

class Fenwick:
    def __init__(self, n):
        self.t = [0] * (n + 1)

    def add(self, index, delta):  # values[index] += delta
        i = index + 1
        while i < len(self.t):
            self.t[i] += delta
            i += i & -i

    def first(self, count):  # sum of the first count values
        s, i = 0, count
        while i > 0:
            s += self.t[i]
            i -= i & -i
        return s

    def range_sum(self, left, right):
        return self.first(right + 1) - self.first(left)

fw = Fenwick(8)
for i, v in enumerate([5, 2, 6, 3, 1, 4, 7, 2]):
    fw.add(i, v)
fw.add(2, 5)
fw.first(7)        # 33
fw.range_sum(2, 6) # 26

Any range is a few blocks and any item sits in a few blocks, so queries and changes are both O(log n).

Use a Fenwick tree for sums and counts: less code, less memory. Use a segment tree for min, max or anything that subtraction cannot undo, since a Fenwick range subtracts two prefixes.

Common mistakes

add takes a change, not a new value: to set index 2 from 6 to 11, call add(2, 5). Keep a plain copy of the values to compute new − old.

0 & -0 is 0, so an add loop starting at slot 0 never moves. That is why slots start at 1.

When the length is not a power of 2, indexes can pass 2n: with 10 items, index 24 is used. Allocate 4n.
