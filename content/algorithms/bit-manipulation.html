A photo app has six on/off settings: grid lines, flash, timer, HDR, location tags and sound. Instead of six true/false values, store one small number where each binary digit is one switch: grid lines in the rightmost digit, flash next, then timer, and so on. Flash and timer on is 000110, the number 6. Saving, copying and comparing all six settings becomes one operation.

File permissions, feature flags and chess engines all store state this way.

A number is a row of switches

In binary, each position is worth double the one to its right: 1, 2, 4, 8, 16, 32. A number is the sum of the positions that are on. Positions count from the right, starting at 0: in 44, bits 2, 3 and 5 are on.

Six operators work on all bits at once, shown on 12 (1100) and 10 (1010):

OperatorRule, bit by bitExample
a & b (AND)1 only if both are 11100 & 1010 = 1000, which is 8
a | b (OR)1 if either is 11100 | 1010 = 1110, which is 14
a ^ b (XOR)1 if they differ1100 ^ 1010 = 0110, which is 6
~a (NOT)flips every bit~5 is −6 (see the mistakes below)

The idea: masks

To touch one switch, build a mask with only that bit on: 1 << i moves a single 1 into position i. Then combine:

  • Check bit i: (x >> i) & 1 is 1 if it is on.
  • Set it: x | (1 << i). OR with 1 forces a 1.
  • Clear it: x & ~(1 << i). The flipped mask is 0 only at bit i, and AND with 0 forces a 0.
  • Toggle it: x ^ (1 << i). XOR with 1 flips a bit.
const isOn = (x, i) => ((x >> i) & 1) === 1;
const turnOn = (x, i) => x | (1 << i);
const turnOff = (x, i) => x & ~(1 << i);
const flip = (x, i) => x ^ (1 << i);

let settings = 0;                // all six off
settings = turnOn(settings, 1);  // flash: 000010
settings = turnOn(settings, 2);  // timer: 000110, which is 6
isOn(settings, 2);               // true
settings = flip(settings, 1);    // flash off again: 000100, which is 4

def is_on(x, i):
    return ((x >> i) & 1) == 1

def turn_on(x, i):
    return x | (1 << i)

def turn_off(x, i):
    return x & ~(1 << i)

def flip(x, i):
    return x ^ (1 << i)

settings = 0                     # all six off
settings = turn_on(settings, 1)  # flash: 000010
settings = turn_on(settings, 2)  # timer: 000110, which is 6
is_on(settings, 2)               # True
settings = flip(settings, 1)     # flash off again: 000100, which is 4

Drop the lowest 1 bit

x & (x - 1) turns off the lowest 1 bit and keeps the rest.

Subtracting 1 turns the lowest 1 into 0 and every 0 below it into 1. AND with the original wipes out exactly those positions. Repeat until nothing is left and you have counted the 1 bits.

It also tests for a power of two, which has exactly one 1 bit: x > 0 && (x & (x - 1)) === 0.

function countOnes(x) {
  let count = 0;
  while (x !== 0) {
    x &= x - 1; // drop the lowest 1
    count++;
  }
  return count;
}

const isPowerOfTwo = (x) => x > 0 && (x & (x - 1)) === 0;

countOnes(44);    // 3
isPowerOfTwo(32); // true
isPowerOfTwo(44); // false

def count_ones(x):
    count = 0
    while x != 0:
        x &= x - 1  # drop the lowest 1
        count += 1
    return count

def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

count_ones(44)        # 3
is_power_of_two(32)   # True
is_power_of_two(44)   # False

In Python 3.10 and later, x.bit_count() counts for you. The "drop the lowest 1" step still matters inside other algorithms, such as Fenwick trees.

XOR finds the odd one out

Every sock ID in a drawer appears twice, except one: [4, 7, 2, 7, 4]. A number XOR itself is 0, a number XOR 0 is itself, and order does not matter. So XOR everything: pairs cancel and the lonely sock is left, with no extra memory.

Step by step: 4 ^ 7 = 3, 3 ^ 2 = 1, 1 ^ 7 = 6, 6 ^ 4 = 2. The middle values look random, but the pairs still cancel.

function unpaired(ids) {
  let result = 0;
  for (const id of ids) result ^= id; // pairs cancel out
  return result;
}

unpaired([4, 7, 2, 7, 4]); // 2

def unpaired(ids):
    result = 0
    for sock_id in ids:
        result ^= sock_id  # pairs cancel out
    return result

unpaired([4, 7, 2, 7, 4])  # 2

Subsets as numbers

Take the sandwich extras C, E and T from Backtracking. Each sandwich is on or off per extra: a 3-bit number. Mask 5 is 101: bits 0 and 2, so C and T. Counting from 0 to 2³ − 1 = 7 visits every sandwich once, with no recursion.

function subsetsByMask(items) {
  const result = [];
  for (let mask = 0; mask < (1 << items.length); mask++) {
    const subset = [];
    for (let i = 0; i < items.length; i++) {
      if ((mask >> i) & 1) subset.push(items[i]); // bit i on: take item i
    }
    result.push(subset);
  }
  return result;
}

subsetsByMask(["C", "E", "T"])[5]; // ["C", "T"]

def subsets_by_mask(items):
    result = []
    for mask in range(1 << len(items)):
        subset = [items[i] for i in range(len(items)) if (mask >> i) & 1]
        result.append(subset)
    return result

subsets_by_mask(["C", "E", "T"])[5]  # ['C', 'T']

Common mistakes

In JavaScript, x & 1 === 0 means x & (1 === 0), always 0, because comparison binds tighter than &, | and ^. Python is the other way round. Always add brackets: (x & 1) === 0.

JavaScript bit operations work on 32-bit signed integers. 1 << 31 is −2147483648, and 2 ** 32 | 0 is 0. Keep masks under 31 bits, use >>> for an unsigned right shift, or use BigInt.

Python integers have no fixed width. A negative number acts as if it had infinitely many 1 bits on the left, so ~5 is −6 and the counting loop never ends for a negative input. Mask to a width first, such as x & 0xFFFFFFFF.

Unix file permissions use three bits per kind of user: read, write and execute. A mode digit of 7 means all three (4 + 2 + 1). Databases, compilers and network code use bit masks for flags because they are small and fast.
