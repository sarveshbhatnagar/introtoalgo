You explore a cave with string tied to the entrance. At every fork you take the first untried passage, unrolling string. At a dead end, you wind it back to the last fork with an untried passage. When it is fully wound back, you have seen the whole cave.

That is depth-first search (DFS). Where BFS spreads out in rings, DFS follows one route as deep as it goes before trying anything else.

The idea: go deep, then back up

In code, recursion is the string: each call waits on the call stack while its child explores. A node's DFS is:

  1. Mark the node seen.
  2. For each unseen neighbour, run DFS on it, all the way, before looking at the next.

As in BFS, the seen mark stops you circling forever.

Each search draws a tree: for every node, the edge it first arrived by.

BFS uses a queue and finishes each distance before the next, so it finds shortest paths. DFS uses a stack (often the call stack) and follows one branch to the end. It is short to write but promises nothing about path length.

The code

// graph: adjacency list, e.g. { A: ["B", "C"], B: ["A", "D"], ... }
function dfs(graph, start) {
  const seen = new Set();
  const order = [];
  function visit(node) {
    seen.add(node);
    order.push(node);
    for (const next of graph[node]) {
      if (!seen.has(next)) visit(next);
    }
  }
  visit(start);
  return order;
}
// dfs(graph, "A") → ["A", "B", "D", "C", "E", "F", "G"]

def dfs(graph, start):
    seen = set()
    order = []

    def visit(node):
        seen.add(node)
        order.append(node)
        for nxt in graph[node]:
            if nxt not in seen:
                visit(nxt)

    visit(start)
    return order
# dfs(graph, "A") → ['A', 'B', 'D', 'C', 'E', 'F', 'G']

You can replace the call stack with your own stack. Pop a node, skip it if seen, otherwise mark it and push its neighbours in reverse, so the visit order matches the recursive version.

function dfsIterative(graph, start) {
  const seen = new Set();
  const order = [];
  const stack = [start];
  while (stack.length > 0) {
    const node = stack.pop();
    if (seen.has(node)) continue; // pushed twice, already handled
    seen.add(node);
    order.push(node);
    const nbrs = graph[node];
    for (let i = nbrs.length - 1; i >= 0; i--) {
      if (!seen.has(nbrs[i])) stack.push(nbrs[i]);
    }
  }
  return order;
}

def dfs_iterative(graph, start):
    seen = set()
    order = []
    stack = [start]
    while stack:
        node = stack.pop()
        if node in seen:
            continue  # pushed twice, already handled
        seen.add(node)
        order.append(node)
        for nxt in reversed(graph[node]):
            if nxt not in seen:
                stack.append(nxt)
    return order

Counting islands in a grid

The most common use of DFS is counting connected components, the separate pieces of a graph. Scan every node. Each unseen one starts a new piece: count it, then run DFS from it to mark the whole piece seen.

On a grid this is the "islands" question: land cells (#) that touch up, down, left or right form one island. The DFS that marks an island is a flood fill, like a paint bucket.

// grid: array of strings. "#" is land, "." is water.
function countIslands(grid) {
  const rows = grid.length, cols = grid[0].length;
  const seen = grid.map((row) => new Array(row.length).fill(false));
  function fill(r, c) {
    if (r < 0 || r >= rows || c < 0 || c >= cols) return; // off the map
    if (grid[r][c] !== "#" || seen[r][c]) return;         // water, or done
    seen[r][c] = true;
    fill(r - 1, c); fill(r + 1, c); fill(r, c - 1); fill(r, c + 1);
  }
  let islands = 0;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === "#" && !seen[r][c]) {
        islands++;  // a piece nobody has reached yet
        fill(r, c); // mark all of it
      }
    }
  }
  return islands;
}

countIslands(["##..#", "#...#", "..#..", "##..."]); // 4

# grid: list of strings. "#" is land, "." is water.
def count_islands(grid):
    rows, cols = len(grid), len(grid[0])
    seen = [[False] * cols for _ in range(rows)]

    def fill(r, c):
        if not (0 <= r < rows and 0 <= c < cols):
            return  # off the map
        if grid[r][c] != "#" or seen[r][c]:
            return  # water, or done
        seen[r][c] = True
        fill(r - 1, c); fill(r + 1, c); fill(r, c - 1); fill(r, c + 1)

    islands = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == "#" and not seen[r][c]:
                islands += 1  # a piece nobody has reached yet
                fill(r, c)    # mark all of it
    return islands

count_islands(["##..#", "#...#", "..#..", "##..."])  # 4

Each cell is touched once and each land cell's 4 sides checked once: O(R × C) time, however many islands. BFS works too.

Common mistakes

Mark a node seen first, before looping over its neighbours. Otherwise A visits B, B sees A unmarked, and the two call each other until the stack overflows.

A 1,000 × 1,000 all-land grid makes recursive DFS one million calls deep. Python stops at about 1,000 by default (RecursionError); JavaScript engines throw "Maximum call stack size exceeded" in the thousands to tens of thousands. For large inputs, use the iterative version or BFS.

DFS takes whatever route its neighbour order gives. On the bus map it reached G in 6 edges when 4 was possible. For "fewest" or "shortest", use BFS.

Garbage collectors find unused memory with a graph walk: start from the variables in use, follow every reference, and anything never reached can be freed.
