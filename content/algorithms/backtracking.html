A sandwich shop offers three extras: cheese, egg and tomato. You want to list every sandwich you could order, from plain bread to all three. Three extras you can do in your head. Twelve give 4,096, and you need a method that never misses one and never writes one twice.

Add an extra. List everything you can still add on top. When you run out, take that extra off and try a different one. That "add it, go deeper, take it back" rhythm is backtracking.

The idea: choose, explore, un-choose

Keep one path: the choices so far. At each decision point, for every option left:

  1. Choose: add the option to the path.
  2. Explore: call yourself recursively to make the remaining decisions.
  3. Un-choose: remove it, so the path is back to what it was, ready for the next option.

The call stack remembers where you were, as in Recursion. Un-choosing lets every branch share one path.

Every backtracking solution is this loop. Problems differ only in what counts as an option, when to record an answer, and which options to skip.

The calls form a tree. A call only offers extras after the last one chosen, so "egg then cheese" never copies "cheese then egg".

Subsets, traced

The path holds one sandwich at a time; the recorded list collects copies.

Step 8 is the key: after popping T the path is CE again. Every call leaves the path as it found it, so the caller's loop carries on.

function subsets(items) {
  const result = [];
  const path = [];
  function explore(start) {
    result.push([...path]); // record a copy, not path itself
    for (let i = start; i < items.length; i++) {
      path.push(items[i]);  // choose
      explore(i + 1);       // explore
      path.pop();           // un-choose
    }
  }
  explore(0);
  return result;
}

subsets(["C", "E", "T"]);
// [[], ["C"], ["C","E"], ["C","E","T"], ["C","T"], ["E"], ["E","T"], ["T"]]

Permutations: same template, different options

Three friends, Ana, Ben and Cy, need a speaking order. Order matters now, so two things change:

  • The options are everyone not used yet, tracked in a used list.
  • Record only when the path is full.

Ana, Ben, Cy is the first full path. Un-choose Cy and Ben, put Cy second: Ana, Cy, Ben.

function permutations(items) {
  const result = [];
  const path = [];
  const used = new Array(items.length).fill(false);
  function explore() {
    if (path.length === items.length) {
      result.push([...path]);
      return;
    }
    for (let i = 0; i < items.length; i++) {
      if (used[i]) continue;
      used[i] = true;     // choose
      path.push(items[i]);
      explore();          // explore
      path.pop();         // un-choose
      used[i] = false;
    }
  }
  explore();
  return result;
}

permutations(["Ana", "Ben", "Cy"]).length; // 6

def permutations(items):
    result = []
    path = []
    used = [False] * len(items)

    def explore():
        if len(path) == len(items):
            result.append(path[:])
            return
        for i in range(len(items)):
            if used[i]:
                continue
            used[i] = True          # choose
            path.append(items[i])
            explore()               # explore
            path.pop()              # un-choose
            used[i] = False

    explore()
    return result

len(permutations(["Ana", "Ben", "Cy"]))  # 6

Choosing makes two updates, so un-choosing undoes both. There are 3 × 2 × 1 = 6 orders.

A puzzle: prune early

Backtracking shines when some choices break a rule. Place 4 queens on a 4 × 4 board so that no two share a row, column or diagonal. Each call picks the column for one row.

The new ingredient is the prune: skip any attacked square. A bad partial board is dropped the moment it goes wrong, along with every board that would grow from it.

To check a square in O(1), keep three sets: used columns, used row - col (down-right diagonals) and used row + col (down-left diagonals). (0, 0) and (1, 1) share row - col = 0, so step 2 skipped (1, 1).

function solveQueens(n) {
  const cols = new Set(), down = new Set(), up = new Set();
  const placed = []; // placed[row] = column of that row's queen
  const solutions = [];
  function explore(row) {
    if (row === n) { solutions.push([...placed]); return; }
    for (let col = 0; col < n; col++) {
      // prune: column or diagonal already taken
      if (cols.has(col) || down.has(row - col) || up.has(row + col)) continue;
      // choose
      cols.add(col); down.add(row - col); up.add(row + col);
      placed.push(col);
      explore(row + 1); // explore
      // un-choose
      cols.delete(col); down.delete(row - col); up.delete(row + col);
      placed.pop();
    }
  }
  explore(0);
  return solutions;
}

solveQueens(4); // [[1, 3, 0, 2], [2, 0, 3, 1]]

def solve_queens(n):
    cols, down, up = set(), set(), set()
    placed = []  # placed[row] = column of that row's queen
    solutions = []

    def explore(row):
        if row == n:
            solutions.append(placed[:])
            return
        for col in range(n):
            if col in cols or row - col in down or row + col in up:
                continue  # prune
            cols.add(col)  # choose
            down.add(row - col)
            up.add(row + col)
            placed.append(col)
            explore(row + 1)  # explore
            cols.remove(col)  # un-choose
            down.remove(row - col)
            up.remove(row + col)
            placed.pop()

    explore(0)
    return solutions

solve_queens(4)  # [[1, 3, 0, 2], [2, 0, 3, 1]]

How much does it cost

Backtracking visits every node of its call tree, and the counts explode: 2²⁰ is about a million and 12! is about 479 million. Use it for small inputs, or where pruning cuts most of the tree away.

Common mistakes

result.push(path) stores a reference to the one shared list, which the un-chooses empty by the end: eight empty lists. Store a copy: [...path] in JavaScript, path[:] in Python.

If choosing touches several things, like used[i] and path or the three queen sets, undo all of them. Miss one and a removed queen still blocks its column, so real answers go missing.

Testing only full boards is plain brute force. Check each choice as you make it.
