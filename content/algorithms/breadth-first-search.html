Drop a stone into a still pond. Rings spread out, and never reach a far point before a near one.

Breadth-first search (BFS) spreads through a graph the same way: everything one edge from the start, then two edges, and so on. So it first reaches each node by the shortest route: in an unweighted graph, BFS finds the fewest-edges path.

The idea: a queue keeps the rings in order

To finish ring 1 before ring 2, use a queue. Take a node from the front and put its new neighbours at the back, behind everything closer to the start.

A graph can have cycles (see Graph Basics), so keep a set of seen nodes, and add a node to it the moment it joins the queue.

  1. Put the start node in the queue. Mark it seen, at distance 0.
  2. Take the node at the front of the queue.
  3. For each unseen neighbour: mark it seen, set its distance to this node's + 1, and add it to the back.
  4. Repeat until the queue is empty.

BFS visits nodes in order of distance from the start. So the first time it reaches a node, it has found a fewest-edges path to it.

The code

Also store each node's parent, the node it was discovered from. To recover the route, follow parents from the goal back to the start, then reverse.

// graph: adjacency list, e.g. { A: ["B", "C"], B: ["A", "D"], ... }
function bfs(graph, start) {
  const dist = { [start]: 0 }; // also our "seen" set
  const parent = { [start]: null };
  const queue = [start];
  let head = 0; // index of the front: O(1) dequeue
  while (head < queue.length) {
    const node = queue[head++];
    for (const next of graph[node]) {
      if (next in dist) continue; // already seen
      dist[next] = dist[node] + 1;
      parent[next] = node;
      queue.push(next);
    }
  }
  return { dist, parent };
}

function pathTo(parent, goal) {
  if (!(goal in parent)) return null; // unreachable
  const path = [];
  for (let at = goal; at !== null; at = parent[at]) path.push(at);
  return path.reverse();
}
// pathTo(bfs(graph, "A").parent, "G") → ["A", "B", "D", "F", "G"]

from collections import deque

# graph: adjacency list, e.g. {"A": ["B", "C"], "B": ["A", "D"], ...}
def bfs(graph, start):
    dist = {start: 0}  # also our "seen" set
    parent = {start: None}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for nxt in graph[node]:
            if nxt in dist:
                continue  # already seen
            dist[nxt] = dist[node] + 1
            parent[nxt] = node
            queue.append(nxt)
    return dist, parent

def path_to(parent, goal):
    if goal not in parent:
        return None  # unreachable
    path = []
    at = goal
    while at is not None:
        path.append(at)
        at = parent[at]
    return path[::-1]
# path_to(bfs(graph, "A")[1], "G") → ['A', 'B', 'D', 'F', 'G']

A, C, E, F, G is also 4 stops. BFS returns whichever shortest path it meets first; both are correct.

BFS on a grid

The fewest moves through a maze is the same problem, on a grid graph. Instead of a dist map, use a 2D array the size of the grid, filled with -1 for "not seen yet".

const DIRS = [[-1, 0], [1, 0], [0, -1], [0, 1]];

// grid: array of strings, "#" is a wall. Start top-left, exit bottom-right.
function stepsToExit(grid) {
  const rows = grid.length, cols = grid[0].length;
  const dist = grid.map((row) => new Array(row.length).fill(-1));
  dist[0][0] = 0;
  const queue = [[0, 0]];
  let head = 0;
  while (head < queue.length) {
    const [r, c] = queue[head++];
    if (r === rows - 1 && c === cols - 1) return dist[r][c];
    for (const [dr, dc] of DIRS) {
      const nr = r + dr, nc = c + dc;
      if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
      if (grid[nr][nc] === "#" || dist[nr][nc] !== -1) continue;
      dist[nr][nc] = dist[r][c] + 1;
      queue.push([nr, nc]);
    }
  }
  return -1; // the exit cannot be reached
}

stepsToExit(["...#.", ".#...", ".#.#.", "...#."]); // 7

from collections import deque

DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

# grid: list of strings, "#" is a wall. Start top-left, exit bottom-right.
def steps_to_exit(grid):
    rows, cols = len(grid), len(grid[0])
    dist = [[-1] * cols for _ in range(rows)]
    dist[0][0] = 0
    queue = deque([(0, 0)])
    while queue:
        r, c = queue.popleft()
        if (r, c) == (rows - 1, cols - 1):
            return dist[r][c]
        for dr, dc in DIRS:
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols):
                continue
            if grid[nr][nc] == "#" or dist[nr][nc] != -1:
                continue
            dist[nr][nc] = dist[r][c] + 1
            queue.append((nr, nc))
    return -1  # the exit cannot be reached

steps_to_exit(["...#.", ".#...", ".#.#.", "...#."])  # 7

A grid with R rows and C columns has R × C nodes and at most 4 edges each, so this is O(R × C) time and space.

For "how far is each cell from the nearest exit?", put every exit in the queue at distance 0 before the loop. The rings grow from all of them at once, and each cell is claimed by its closest exit. One BFS instead of one per exit.

Common mistakes

Mark a node only when it leaves the queue and it can be added several times first: on the bus map, D would be added by B and again by C. On a big grid the queue fills with copies. Mark it seen when you add it.

In JavaScript, queue.shift() is O(n) per call, so BFS becomes O(V²). Keep a head index instead. In Python, use collections.deque and popleft(), not list.pop(0).

BFS counts edges, not minutes or kilometres. With roads of 2 and 30 minutes, the path with fewer roads can be slower. For weighted edges, use Dijkstra's algorithm, which grows the rings by total weight.

"People you may know" starts from friends of friends: nodes at distance 2 from you. Puzzle solvers use BFS to find the fewest moves for a sliding-tile puzzle.
