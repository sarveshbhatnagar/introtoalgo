About introtoalgo

introtoalgo started in 2017 as a small blog about algorithms. It is now a free place to learn algorithms, practise them, and understand AI well enough to use it with confidence.

How it is built

Every lesson starts with a concrete problem, traces the idea by hand, and only then shows code. Practice problems run in your browser: JavaScript in a sandboxed worker, Python through Pyodide. Nothing you write is sent anywhere.

Your progress, saved code and theme choice live in your browser's local storage. Clearing site data resets them. There are no accounts.
