DP on Strings

Compare two strings with a table of prefixes: find the longest common subsequence, then the fewest edits that turn one word into another.

When you ask version control what changed in a file, it does not compare line 1 with line 1. It finds the largest set of lines that appear in both versions in the same order, possibly with other lines between them, and reports everything else as added or removed.

Shrink lines to letters. Which is the longest sequence of letters that appears in order, not necessarily adjacent, in both ROAD and BOARD? It is OAD, length 3: the longest common subsequence, or LCS.

#Prefixes are the subproblems

A word of length 20 has over a million subsequences, so listing them is out. Look at the last letter of each word instead.

  • If they match, like the final D of ROAD and BOARD, use it. The rest is the LCS of ROA and BOAR.
  • If they differ, at least one of them is not used. Drop the last letter of one word or the other, and keep the better result.

Either way you get the same question about shorter prefixes, so build a table with one word down the side and the other across the top.

#The five steps

  1. State. L[i][j] is the length of the LCS of the first i letters of a and the first j letters of b.
  2. Recurrence. If a[i − 1] == b[j − 1], then L[i][j] = L[i − 1][j − 1] + 1. Otherwise L[i][j] = max(L[i − 1][j], L[i][j − 1]).
  3. Base cases. L[0][j] = 0 and L[i][0] = 0: an empty word shares nothing.
  4. Order. Each cell reads up, left and up-left, as on a grid, so fill row by row, left to right.
  5. Answer. L[len(a)][len(b)], the bottom-right cell.

Row 0 and column 0 are the empty prefix, so row i is about the letter a[i − 1].

Longest common subsequence
function lcsLength(a, b) {
  const L = Array.from({ length: a.length + 1 }, () => new Array(b.length + 1).fill(0));
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      if (a[i - 1] === b[j - 1]) {
        L[i][j] = L[i - 1][j - 1] + 1; // use the matching letter
      } else {
        L[i][j] = Math.max(L[i - 1][j], L[i][j - 1]); // drop one letter
      }
    }
  }
  return L[a.length][b.length];
}
 
lcsLength("ROAD", "BOARD"); // 3

#Same table, different question: edit distance

A spell checker sees the typo ROAD and wonders if you meant BOARD. It measures closeness by the edit distance: the fewest single-letter inserts, deletes or replacements that turn one word into the other.

Use prefixes again. Matching last letters cost nothing. Otherwise the last edit was one of three, each pointing at a neighbouring cell.

  1. State. E[i][j] is the fewest edits that turn the first i letters of a into the first j letters of b.
  2. Recurrence. If the letters match, E[i][j] = E[i − 1][j − 1]. Otherwise E[i][j] = 1 + min(E[i − 1][j − 1], E[i − 1][j], E[i][j − 1]): replace, delete or insert.
  3. Base cases. E[i][0] = i (i deletes) and E[0][j] = j (j inserts).
  4. Order and answer: the same as for LCS.

The corner says 2: replace R with B, then insert R before the D. Check one cell: row O, column O is a match, so it copies the diagonal (row R, column B), which holds 1.

Edit distance
function editDistance(a, b) {
  const E = Array.from({ length: a.length + 1 }, () => new Array(b.length + 1).fill(0));
  for (let i = 0; i <= a.length; i++) E[i][0] = i; // delete everything
  for (let j = 0; j <= b.length; j++) E[0][j] = j; // insert everything
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      if (a[i - 1] === b[j - 1]) {
        E[i][j] = E[i - 1][j - 1]; // free match
      } else {
        E[i][j] = 1 + Math.min(E[i - 1][j - 1], E[i - 1][j], E[i][j - 1]);
      }
    }
  }
  return E[a.length][b.length];
}
 
editDistance("ROAD", "BOARD"); // 2

Key idea

With two strings, the state is almost always "the first i characters of one and the first j of the other". Then ask what happens to each last character.

ApproachTimeSpaceWhy
LCS tableO(m × n)O(m × n)One cell per pair of prefixes, constant work per cell.
Edit distance tableO(m × n)O(m × n)Same table size. Keep only two rows for O(n) space if you need just the number.

#Common mistakes

Comparing a[i] instead of a[i − 1]

Row 0 is the empty prefix, so row i is about a[i − 1]. Writing a[i] compares the wrong letters and reads past the end on the last row.

Confusing subsequence with substring

A substring is one unbroken run; a subsequence may skip letters. OAD is a subsequence of BOARD, not a substring. Longest common substring uses a different recurrence: a mismatch resets the cell to 0.

Edit distance base cases set to 0

Turning ROA into the empty word takes 3 deletes, not 0. Leave the first row and column at 0 and every answer comes out too small.

In the real world

Diff tools build on LCS. Spelling suggestions, fuzzy search and DNA comparison use edit distance, often with different costs per kind of edit.

#Check yourself

Quick check

What is the length of the longest common subsequence of "TEAM" and "MEAT"?

  1. Not quite. E then A appears in order in both words.
  2. Right. EA appears in order in both. No 3 letters work: T is first in TEAM but last in MEAT, and M the reverse.
  3. Not quite. Same letters, different order. A subsequence must keep the order.

In the LCS table, the letters for cell [i][j] differ. L[i − 1][j] = 2 and L[i][j − 1] = 3. What is L[i][j]?

  1. Right. On a mismatch, take the better of dropping one letter or the other: max(2, 3) = 3.
  2. Not quite. You add 1 only on a match, and to the diagonal cell.
  3. Not quite. The two options are alternatives, not parts to add.

What is the edit distance from "CAT" to "CUT"?

  1. Right. Replace A with U. C and T match and cost nothing.
  2. Not quite. Deleting A and inserting U works, but one replace does the same job.
  3. Not quite. The words differ, so at least one edit is needed.
