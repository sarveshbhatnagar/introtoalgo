DP on Strings

Compare two strings with a table of prefixes: find the longest common subsequence, then the fewest edits that turn one word into another.

When you change a file and ask version control what is different, it does not compare line 1 with line 1 and give up after the first insert. It finds the largest set of lines that appear in both versions in the same order, even with other lines between them. It keeps those and reports everything else as added or removed.

Shrink the lines to letters and you get a puzzle you can do by hand. What is the longest sequence of letters that appears, in order, in both ROAD and BOARD? The letters do not have to sit next to each other, only keep their order. The answer is OAD, length 3. This is the longest common subsequence, or LCS.

#Prefixes are the subproblems

A word of length 4 has 16 subsequences and one of length 20 has over a million, so listing them is out. Instead, look at the last letter of each word.

  • If they match, like the final D of ROAD and BOARD, use that letter. The rest of the answer is the LCS of what comes before: ROA and BOAR.
  • If they differ, they cannot both be the last letter of a shared sequence. So at least one of them is not used: drop the last letter of one word or of the other, and keep the better result.

Either way the question becomes the same question about shorter prefixes: the first i letters of one word and the first j of the other. That gives a table with one word down the side and the other across the top.

#The five steps

  1. State. L[i][j] is the length of the LCS of the first i letters of a and the first j letters of b.
  2. Recurrence. If a[i − 1] == b[j − 1], then L[i][j] = L[i − 1][j − 1] + 1. Otherwise L[i][j] = max(L[i − 1][j], L[i][j − 1]).
  3. Base cases. L[0][j] = 0 and L[i][0] = 0: an empty word shares nothing.
  4. Order. Each cell reads up, left and diagonally up-left, as on a grid. Row by row, left to right.
  5. Answer. L[len(a)][len(b)], the bottom-right cell.

Note the shift: row i is about the letter a[i − 1]. The extra row and column at index 0 stand for the empty prefix, and they are what make the base cases this simple.

Longest common subsequence
function lcsLength(a, b) {
  const L = Array.from({ length: a.length + 1 }, () => new Array(b.length + 1).fill(0));
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      if (a[i - 1] === b[j - 1]) {
        L[i][j] = L[i - 1][j - 1] + 1; // use the matching letter
      } else {
        L[i][j] = Math.max(L[i - 1][j], L[i][j - 1]); // drop one letter
      }
    }
  }
  return L[a.length][b.length];
}
 
lcsLength("ROAD", "BOARD"); // 3

#Same table, different question: edit distance

A spell checker sees the typo ROAD and wonders if you meant BOARD. It measures how close two words are by the fewest single-letter edits that turn one into the other, where an edit is inserting a letter, deleting a letter or replacing one letter with another. This is the edit distance.

The subproblems are prefixes again. Think about the last letters. If they match, they cost nothing: keep them and solve the shorter prefixes. If not, the last edit was one of three things, and each one points at a neighbouring cell.

  1. State. E[i][j] is the fewest edits that turn the first i letters of a into the first j letters of b.
  2. Recurrence. If the letters match, E[i][j] = E[i − 1][j − 1]. Otherwise E[i][j] = 1 + min(E[i − 1][j − 1], E[i − 1][j], E[i][j − 1]): replace, delete or insert.
  3. Base cases. E[i][0] = i, since turning i letters into nothing takes i deletes. E[0][j] = j: building j letters from nothing takes j inserts.
  4. Order and answer: the same as for LCS.

Edit distance
function editDistance(a, b) {
  const E = Array.from({ length: a.length + 1 }, () => new Array(b.length + 1).fill(0));
  for (let i = 0; i <= a.length; i++) E[i][0] = i; // delete everything
  for (let j = 0; j <= b.length; j++) E[0][j] = j; // insert everything
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      if (a[i - 1] === b[j - 1]) {
        E[i][j] = E[i - 1][j - 1]; // free match
      } else {
        E[i][j] = 1 + Math.min(E[i - 1][j - 1], E[i - 1][j], E[i][j - 1]);
      }
    }
  }
  return E[a.length][b.length];
}
 
editDistance("ROAD", "BOARD"); // 2

Key idea

With two strings, the state is almost always "the first i characters of one and the first j of the other". Then ask what happens to the last character of each.

ApproachTimeSpaceWhy
LCS tableO(m × n)O(m × n)One cell per pair of prefixes, constant work per cell.
Edit distance tableO(m × n)O(m × n)Same table size. Keep only two rows for O(n) space if you need just the number.

#Common mistakes

Comparing a[i] instead of a[i − 1]

The table has one more row than a has letters, because row 0 is the empty prefix. So row i is about a[i − 1]. Writing a[i] compares the wrong letters and reads past the end on the last row.

Confusing subsequence with substring

A substring must be one unbroken run of letters; a subsequence may skip letters. OAD is a subsequence of BOARD but not a substring. The longest common substring uses a different recurrence: on a mismatch the cell becomes 0, because the run is broken.

Edit distance base cases set to 0

Turning ROA into the empty word takes 3 deletes, not 0. If the first row and column are left at 0, every answer comes out too small.

In the real world

Text diff tools build on the LCS idea, and spelling suggestions, fuzzy search and DNA sequence comparison all use variants of edit distance, often with different costs for each kind of edit.

#Check yourself

Quick check

What is the length of the longest common subsequence of "TEAM" and "MEAT"?

  1. Not quite. There are longer ones. E then A appears in that order in both words.
  2. Right. EA appears in order in both. No 3-letter sequence works: T comes first in TEAM but last in MEAT, and M is the reverse.
  3. Not quite. Both words use the same letters, but in a different order. A subsequence must keep the order.

In the LCS table, the letters for cell [i][j] differ. L[i − 1][j] = 2 and L[i][j − 1] = 3. What is L[i][j]?

  1. Right. On a mismatch, take the better of dropping one letter or the other: max(2, 3) = 3.
  2. Not quite. Adding 1 only happens when the two letters match, and it adds to the diagonal cell.
  3. Not quite. The two options are alternatives, not parts to add together.

What is the edit distance from "CAT" to "CUT"?

  1. Right. Replace A with U. C and T match and cost nothing.
  2. Not quite. Deleting A and inserting U works, but a single replace does the same job in one edit.
  3. Not quite. The words differ in one letter, so at least one edit is needed.
